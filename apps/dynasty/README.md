# Dynasty of Champions

Static command center for the **Dynasty of Champions** Sleeper dynasty chain (2019–2026). Uses public Sleeper read APIs only — no backend, no secrets.

## Local development

```bash
npm install
npm run dev
```

## Tests and static publish

```bash
npm run test
npm run build
npm run publish-static   # writes ../dynasty-1581d86a/ at repo root
```

Tab audio: `npm run generate-audio` (see `AUDIO_CREDITS.md`).
