Vehicle Wraps | New York / Tri-State

Vehicle wraps and fleet graphics for New York / Tri-State

Arc plans wrap layouts from your logo and vehicle dimensions, prepares print files, and coordinates application through install partners. For commercial vehicles, the operating carrier supplies its legal name and USDOT number; FMCSA rule 49 CFR 390.21 requires them on both sides in sharply contrasting letters. Arc lays out the markings as provided.

FAQ

Vehicle wrap questions

Does Arc install vehicle wraps?

Application is through Arc's install partners. Arc handles design, file prep, and coordination with the shop doing the install.

What should I send for a wrap quote?

Send vehicle make and model, photos of each side, logo files, and the project street address or fleet yard location. Email arc@arcsignco.com with the address in the subject line.

Can Arc wrap a delivery fleet?

Yes, when dimensions and artwork are available. Arc scopes each vehicle separately unless you provide a fleet count and schedule.
